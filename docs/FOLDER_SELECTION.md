# 文件与文件夹多选

文件树中的选择与右侧打开的文档分别管理；文件、普通文件夹和完整 iWork 文档包都可加入选择。仅操作当前窗口工作区中的项目。

| 操作 | 行为 |
| --- | --- |
| 普通点击 | 单选并保留原有行为：文件打开，文件夹展开或折叠 |
| ⌘ / Ctrl + 点击 | 增选或取消一个项目，不打开文件、不展开目录 |
| Shift + 点击 | 按屏幕上的树顺序连续选择；⌘ / Ctrl + Shift 追加区间 |
| 树行聚焦时 ⌘ / Ctrl + A | 选择当前所有可见行，不读取未展开目录 |
| 方向键 / Home / End | 移动选择；加 Shift 扩展区间 |
| Escape / 点击树的空白处 | 清空选择，不关闭当前文档 |
| 右键 / 行尾 ••• | 已选行保留整个选择；未选行改为单选 |
| 拖动任一已选行 | 将整个选择移到目标文件夹或工作区根目录 |
| 移动到文件夹… | 桌面端选择一次目标，然后逐项移动 |
| 移到废纸篓 / 树行聚焦时 ⌘ / Ctrl + Backspace | 确认后逐项移到 macOS 废纸篓 |

选择计数显示在侧栏底部。目录折叠、外部删除或切换工作区会清除不可见的选择；只按可见行连选或全选，不隐式扫描子目录。编辑器、新建和重命名输入框中的快捷键不会触发批量删除。

## 文件安全边界

父目录和其子项同时选中时，按最上层目录操作一次，不重复移动或删除子项。多选菜单不提供含糊的批量重命名或新建。

批量移动在第一项提交前检查所有源、目标和包含当前编辑文档的保存结果，再复用已有的原生安全移动命令逐项执行。不能移动工作区根目录、移出工作区、移动到自身或后代、覆盖同名项或将多个同名源合并到同一个目标。原生层仍验证工作区代际、路径和文件身份。

批量移到废纸篓只确认一次，确认中显示项目数量和目录递归范围。包含当前文档时仍经过保存／显式放弃确认；不包含当前文档时不会强制保存无关草稿。不提供永久删除。

批量操作**不是全有或全无事务**。遇到失败或不确定结果立即停止，不再处理其余项目；明确报告已确认完成数量，保留失败及未尝试项目的选择，不自动撤销已完成操作。外部磁盘变化仍可能让部分项目已不存在；结果不确定时需要检查刷新后的源和目标目录。

浏览器 Demo 使用相同选择交互，内部拖动和废纸篓只修改内存；没有原生目录选择器，也不会操作真实磁盘。macOS 原生拖放和系统废纸篓仍需在独立的合成测试文件夹中验收。

# Markdown 格式回归验证

适用于 `0.2.0-beta.2`。测试使用仓库自建的[任务样例](fixtures/markdown-task-matrix.md)、[格式样例](fixtures/markdown-format-matrix.md)和相对路径图片，不依赖用户的私人文件。

## 本次修复

- 预览和分栏中的任务框可直接勾选，经过现有的 600 ms 自动保存协调器写回原文件；`Command-S` 可立即保存。
- 每次预览勾选形成独立的撤销步骤，支持撤销、重做和跨模式切换；WebKit 点击后保留任务框焦点。
- 兼容深空格、多个 Tab、不换行空格和全角空格缩进的任务续行，以及缺少标记后空格的任务。显示层恢复列表结构，文件原文不被格式化重写。
- 只改变目标任务的状态字符，保留原始缩进、CRLF 和混合换行；撤销恢复原有状态，包括大写 `[X]`。
- 编辑、分栏和预览共用原始文档状态；切换文件、工作区和保存冲突时继续执行原有保护。

## 验证边界

- 真实文件保存与冲突处理由应用集成测试覆盖；WKWebView 测试验证本机渲染和交互，不代表在另一台 Intel Mac 上完成了文件系统端到端验收。
- 明确的缩进代码块或围栏代码块不会猜测为任务。标准写法仍建议 `- [ ] 文字`，并使用一致的列表缩进。
- 编辑光标所在区域显示源码；活动区域与阅读预览不追求像素完全相同。
- 复杂、嵌套或超限表格继续回退源码编辑；任意 HTML 不作为富文本执行。
- 安装包为临时签名、未经 Apple 公证的 Beta，要求 macOS 12 或更高版本。

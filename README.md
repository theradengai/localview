# LocalView

A lightweight local-first file workspace.

## Vision

Open a file, see the folder context.

LocalView is a macOS-first desktop app for browsing and editing local documents without vaults, imports, or database indexing.

## MVP

- Open Markdown files and show their folder tree context
- Edit Markdown and preview rendering
- Preview HTML files with local assets
- Browse real filesystem structure
- No import, no workspace database

## Planned stack

- Tauri 2
- TypeScript
- CodeMirror 6
- Markdown renderer

## Roadmap
